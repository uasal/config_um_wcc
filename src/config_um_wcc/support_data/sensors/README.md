Added HWK4123 data 10/7/2026. 
The data is synthetically generated by using end points of the calibration to interpolate the full curves. 
The dark current curve assumes an exponential dependence. The gain curve is NOT like the case for the IMX sensor where 
the units of gain are 0.1 dB. Instead the gain here is in units of 1,8,16,32 directly applied to the electron output.
So, the `gain` parameter for the IMX and the `gain` parameter for the HWK have different units and meanings, but 
functionally they should help set the read noise correctly for their sensor.
